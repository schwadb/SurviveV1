Quick Start

From zero to a running offline survival server. Steps 1–4 take ~30 minutes; content download takes days.

1
Prepare the Raspberry Pi

Flash Raspberry Pi OS 64-bit (Bookworm) to a microSD using Raspberry Pi Imager. Enable SSH in the Imager settings before flashing. Boot and connect via SSH or keyboard/monitor.

2
Clone the Repository & Run the Installer
git clone https://github.com/schwadb/SurviveV1.git ~/SurviveV1
cd ~/SurviveV1
sudo bash setup/install.sh

The installer (~15–30 min) installs: Kiwix, Kolibri, Jellyfin, Calibre, Ollama, nginx, Samba, avahi-daemon, ufw, rclone, yt-dlp, and all Python dependencies.

3
Mount Your Storage Drive
# Find your drive
lsblk

# Format if new — WARNING: erases all data
sudo mkfs.ext4 /dev/sda1   # replace sda1 with your drive

# Mount
sudo mkdir -p /mnt/survive
sudo mount /dev/sda1 /mnt/survive

# Auto-mount on boot
echo "UUID=$(sudo blkid -s UUID -o value /dev/sda1)  /mnt/survive  ext4  defaults,noatime  0  2" \
  | sudo tee -a /etc/fstab
4
Configure
nano ~/SurviveV1/config/survive.conf

# Key settings to review:
SURVIVE_STORAGE_PATH="/mnt/survive"
MAP_REGION="north-america"    # or: south-america, europe, africa, asia, world
CONTENT_VIDEOS="Y"            # set N to skip video download
SKIP_AI_HAT="false"           # set true if you don't have the AI Hat
5
Download Content (takes days — let it run)
# Download everything
bash download/download_all.sh

# Or download individual categories:
bash download/kiwix_content.sh       # Wikipedia, Stack Exchange (~100–180 GB)
bash download/videos.sh              # Survival video channels (~150 GB)
bash download/books_pdfs.sh          # Military manuals, medical PDFs (~20 GB)
bash download/maps.sh --region us    # US maps (~20 GB)
bash download/kolibri_content.sh     # Khan Academy (~200 GB)
bash download/gaps_content.sh        # Expert-identified gap-filling content

6
Set Up the AI Assistant
# Pull AI models (choose based on RAM)
bash ai/setup_ollama.sh

# Or manually:
ollama pull phi3:mini      # 2.3 GB — recommended for RPi 5
ollama pull tinyllama      # 637 MB — fastest, basic quality
ollama pull mistral:7b-q4  # 4.1 GB — best quality, needs 6 GB RAM
7
Start Everything
bash scripts/start_services.sh

# Dashboard available at:
http://localhost:8080
http://survive.local:8080   # from other devices on same network
# Useful management commands:
bash scripts/status.sh           # check all service status
bash scripts/stop_services.sh    # stop everything
bash scripts/update_content.sh   # update downloaded content
8
Cloud Backup (optional — do while internet available)
# Set up cloud storage (run once)
bash sync/setup_rclone.sh gdrive     # Google Drive
bash sync/setup_rclone.sh dropbox    # Dropbox

# Sync content to cloud
bash sync/sync_to_cloud.sh gdrive

# Schedule nightly sync when internet is available
sudo bash sync/schedule_sync.sh gdrive

# Restore from cloud (after hardware replacement)
bash sync/sync_from_cloud.sh gdrive

Troubleshooting
# Dashboard not loading
bash scripts/status.sh
tail -f /tmp/survive_dashboard.log

# Wikipedia empty
ls /mnt/survive/zim/    # should show .zim files

# AI not responding
ollama serve &
ollama list             # verify models installed

# Check disk space
df -h /mnt/survive
du -sh /mnt/survive/*

# Check Pi temperature (avoid throttling)
vcgencmd measure_temp
sudo cpufreq-set -g powersave  # extend battery life

Gaps Analysis

Expert-identified content gaps vs. standard prepper repositories. Based on research into Creek Stewart, Cody Lundin, Les Stroud, Dave Canterbury, John "Lofty" Wiseman, James Wesley Rawles, Dr. Joseph Alton (Doom and Bloom), Fernando "Ferfal" Aguirre, Laurence Gonzales, and others.

Tier 1 — Critical / Life-or-death
Tier 2 — Significant gap
Tier 3 — Present but shallow

TIER 1 — Critical Gaps (Life-or-Death)

1. Advanced Survival Medicine

Standard repos have basic first aid only. Missing: damage control surgery, austere-environment medicine, drug equivalences, antibiotic protocols.

Key resources added:

  • "The Survival Medicine Handbook" — Dr. Joe & Amy Alton (700+ pages — doomandbloom.net)
  • "Survival and Austere Medicine" 3rd Ed — FREE PDF at griddownmed.blog
  • "Emergency War Surgery" — NATO/Borden Institute (public domain)
  • "Wilderness Medicine: Beyond First Aid" — Dr. William Forgey
  • "Ditch Medicine" — Hugh Coffee (Bier blocks, IV access in field)
  • "Alton's Antibiotics and Infectious Disease" — Alton (1st Place Book Excellence Award)
  • Doom and Bloom podcast + YouTube (@DoomAndBloom) — Dr. Bones & Nurse Amy
  • The Patriot Nurse + Skinny Medic (YouTube) — field medicine, TCCC
2. Emergency Childbirth & Obstetrics

Entirely absent from standard repos. One of the highest-stakes grid-down scenarios — postpartum hemorrhage kills in under 90 minutes.

  • "Emergency Childbirth" — Gregory White (public domain, archive.org)
  • "A Book for Midwives" — Hesperian Foundation (FREE at hesperian.org)
  • "Ina May's Guide to Childbirth" — Ina May Gaskin
  • "Heart & Hands" — Elizabeth Davis
  • WHO Safe Motherhood Practical Guide (FREE)
  • Peace Corps Maternal Child Health Guide (FREE)
3. Dental Emergency Skills

Zero dental content in standard repos. An untreated tooth abscess leads to sepsis → death. This is life-or-death, not cosmetic.

  • "Where There Is No Dentist" — Murray Dickson (Hesperian, FREE) — includes Atraumatic Restorative Treatment (ART) for cavity filling without a drill
  • Tooth extraction: teeth are EASED out, not pulled; clear infection with antibiotics first
  • Temporary filling materials: zinc oxide eugenol, Cavit, dental cement
  • Oil of cloves / eugenol — most effective natural dental analgesic
  • Key: offgridweb.com emergency dentistry series
4. Psychiatric & Mental Health in Collapse

The single most neglected topic in prepper content. Studies show 65% of disaster survivors develop new-onset depression/anxiety; 45% of OKC bombing survivors had a psychiatric disorder at 6 months.

  • "Where There Is No Psychiatrist" — Vikram Patel (Hesperian, FREE)
  • "WHO Psychological First Aid" — FREE at who.int
  • "SHTF Psychology" — Michael Harris — collapse-specific mindset preparation
  • "Mental Health Survival Kit and Withdrawal from Psychiatric Drugs" — Peter Gøtzsche — CRITICAL for patients dependent on psychiatric meds when supply chains fail
  • CDC/NIOSH Disaster Psychology paper — Everly (FREE at cdc.gov)
  • "Deep Survival" — Laurence Gonzales — why some live and others die
  • "The Unthinkable" — Amanda Ripley — disaster psychology
  • The psychological cost of violence — almost never addressed in prepper content
5. Community Organization & Social Survival

Individual/family focus only in standard repos. Community is the #1 survival multiplier — lone wolves die first.

  • "A Paradise Built in Hell" — Rebecca Solnit — how communities ACTUALLY behave post-disaster (counters the "everyone turns savage" myth with historical evidence)
  • "The Knowledge" — Lewis Dartnell — rebuilding civilization from scratch
  • "The Modern Survival Manual" — Fernando Aguirre (Argentina 2001 REAL collapse experience)
  • FEMA Community Resilience Planning Guide (FREE)
  • Sphere Handbook 2018 — humanitarian standards (FREE)
6. Sanitation Without Infrastructure

Sewage failure causes disease outbreaks within 72 hours. This kills more people than violence after disasters.

  • "The Humanure Handbook" — Joseph Jenkins (FREE at humanurehandbook.com — full book)
  • Peace Corps Latrine Construction Guide (FREE)
  • WHO Sanitation and Health Guide (FREE)
  • Greywater design: Create an Oasis with Greywater — Art Ludwig
7. Animal Husbandry

Zero livestock content in standard repos. Long-term food security requires animals — gardens alone cannot sustain protein needs.

  • Storey's Guide series — Chickens, Dairy Goats, Pigs, Rabbits (the definitive standard; Amazon #1 bestseller)
  • "The Backyard Homestead Guide to Raising Farm Animals" — Gail Damerow
  • "Secret Livestock of Survival" — Rick Austin (specifically for retreat/homestead)
  • "Butchering Poultry, Rabbit, Lamb, Goat, and Pork" — Adam Danforth
  • FAO Goat, Poultry, Pig production guides (FREE at fao.org)
  • Weed 'em and Reap + Jill Winger (YouTube)

TIER 2 — Significant Gaps

8. Seed Saving (not just buying seeds)

Most repos mention buying seeds, not saving them. After Year 1, bought seeds run out — seed saving is essential for food security beyond the first growing season.

  • "Seed to Seed" — Suzanne Ashworth (THE definitive reference — isolation distances, fermentation, biennials)
  • "The Seed Garden" — Seed Savers Exchange (seedsavers.org)
  • Best beginner crops: beans, peas, tomatoes, lettuce (self-pollinating, no cross-pollination risk)
  • Storage rule: temperature(°F) + relative humidity ≤ 100
  • Mylar bags + oxygen absorbers + silica gel = 10+ year storage
  • Southern Exposure Seed Saving Guide (FREE PDF)
9. Beekeeping

Not in standard repos at all. Critical for pollination (food production), honey (wound treatment), beeswax (candles, waterproofing), and mead (alcohol/medicine).

  • "The Beekeeper's Handbook" — Diana Sammataro
  • "Natural Beekeeping" — Ross Conrad
  • "Top-Bar Beekeeping" — Les Crowder (low-cost equipment)
  • Varroa mite management — #1 cause of colony collapse
  • Honey as wound treatment: hygroscopic, antibacterial, antifungal
  • FAO Beekeeping Guide (FREE)
  • Penn State Beekeeping Guide (FREE)
10. Blacksmithing & Metalwork
  • "The Complete Modern Blacksmith" — Alexander Weygers
  • "Basic Blacksmithing" — D. Harries (FREE PDF at northernbush.com)
  • "Practical Blacksmithing" — M.T. Richardson (4 vols, public domain, archive.org)
  • "The Home Blacksmith" — Ryan Ridgway (40 step-by-step projects)
  • Improvised forge: brake drum + hair dryer + coal
  • Blackbear Forge + Alec Steele (YouTube)
11. Leather Brain Tanning
  • "Deerskins into Buckskins" — Matt Richards (the definitive guide)
  • Brain tanning: every animal has enough brain to tan its own hide
  • Bark/vegetable tanning with natural tannins (oak bark, sumac)
  • Rawhide vs. buckskin — different properties and uses
  • Townsends (YouTube) — 18th century leather techniques
12. Soap Making from Wood Ash
  • "The Soapmaker's Companion" — Susan Miller Cavitch
  • Lye extraction from wood ash leaching (potassium hydroxide)
  • Saponification ratios for animal fats vs. vegetable oils
  • Cold process vs. hot process
  • Soft soap (KOH/potassium) vs. hard soap (NaOH/sodium)
13. Fermentation & Brewing
  • "The Art of Fermentation" — Sandor Katz (the definitive text)
  • "Wild Fermentation" — Sandor Katz
  • Lacto-fermentation: preserves without canning equipment (sauerkraut, kimchi)
  • Vinegar making (acetic acid for cleaning, preservation, cooking)
  • Mead, kefir, kvass, kombucha, medicinal tinctures
  • Alcohol as fuel, antiseptic, and barter item
  • City Steading Brews + Homesteady (YouTube)
14. Water Well Construction
  • "Hand-Dug Wells and Their Construction" — Watt & Wood (IT Publications)
  • Peace Corps Manual Well Drilling guide (FREE)
  • WHO Drinking Water Quality Guidelines (FREE)
  • Site selection, water table reading, concrete ring casing
  • Contamination prevention (sanitary seal), hand pump installation
15. Security & Perimeter Defense
  • "Contact!" — Max Velocity (post-collapse tactical)
  • "Holding Your Ground" — Joe Nobody
  • FM 7-8 Infantry Rifle Platoon (public domain) — layered defense concepts
  • FM 21-60 Visual Signals — hand signals (public domain, FREE)
  • SH 21-76 Ranger Handbook (FREE PDF)
  • Dogs and livestock as early warning systems
  • Noise / light / litter discipline

TIER 3 — Shallow Coverage

16. Morse Code / CW
  • "The Art and Skill of Radio-Telegraphy" — W. Pierpont N0HFF (FREE PDF at qsl.net/n9bor/n0hff.pdf)
  • LCWO.net — Learn CW Online (browser-based, free)
  • CW works at signal levels where voice fails; can run on milliwatts
  • SOS (... --- ...) — universally recognized, no radio required (mirror, flashlight)
17. Radio Programming (CHIRP / Baofeng)
  • CHIRP software — free, open-source, standard for Baofeng UV-5R programming
  • RepeaterBook.com — find local repeaters
  • Key pre-programmed frequencies: MURS, GMRS, 146.520 MHz (2m calling), NOAA weather
  • Ham Radio Crash Course (K0PIR) + David Casler KE0OG (YouTube)
18. Pressure Canning Safety
  • NCHFP (nchfp.uga.edu) — authoritative USDA-funded tested recipes
  • Botulism mechanism: only pressure canning (240°F/116°C) kills C. botulinum spores in low-acid foods
  • Altitude adjustment tables (every 1,000 ft above sea level changes processing time)
  • Common failure modes: false seals, under-processing, inadequate headspace
19. Permaculture Design
  • "Gaia's Garden" — Toby Hemenway (best accessible permaculture book)
  • "Permaculture: A Designers' Manual" — Bill Mollison (technical bible)
  • Zone design (0–5) for energy efficiency
  • Food forest: 7 layers (canopy, sub-canopy, shrub, herbaceous, ground cover, root, vine)
  • Water harvesting earthworks: swales, berms, ponds

Expert Summaries
Creek Stewart — Weather the Storm
  • Will to Survive = #1 skill
  • Priority order: Shelter → Water → Fire → Food
  • Improvisation over gear dependency
Dave Canterbury — Pathfinder School
  • 10 Cs of Survivability framework
  • Cutting, Combustion, Cover, Container, Cordage, Cotton, Cargo tape, Compass, Candling, Canvas
  • Heavy emphasis on primitive skills
Cody Lundin — Aboriginal Living Skills
  • Thermoregulation = #1 priority
  • Primitive living: brain tanning, earth ovens, hide shelters
  • Calm mindset over equipment
Les Stroud — Survivorman
  • Psychological preparedness over gear
  • Signaling and rescue as primary priorities when lost
  • Urban survival often more dangerous than wilderness
James Wesley Rawles — SurvivalBlog
  • "Beans, Bullets, Band-Aids" framework
  • Community retreat model vs. lone wolf
  • Amateur radio as essential communications
  • Legal and financial preparedness alongside physical
Fernando "Ferfal" Aguirre — Argentina 2001
  • Real collapse experience — not theoretical
  • Cities did NOT empty — rural isolation was MORE dangerous
  • Security was the #1 daily concern, not food or water
  • Keep skills marketable; economic collapse ≠ zombie apocalypse

Hailo AI Hat Setup

The Hailo-8L AI Hat provides up to 13 TOPS of neural processing acceleration, significantly speeding up local AI inference on the Raspberry Pi 5.

Performance Benchmarks — RPi 5 + Hailo-8L
TaskCPU OnlyWith AI Hat
Image classification~400 ms~15 ms
Object detection~1,200 ms~30 ms
Text generation (7B model)~2 tok/s~8 tok/s
Question answering~3 s~0.8 s
Running WITHOUT the AI Hat

The system falls back to CPU inference automatically:

  • tinyllama: ~2–3 tokens/second on RPi 5
  • phi3:mini: ~1–2 tokens/second
  • Still very usable for survival queries

Set in config:

SKIP_AI_HAT="true"
Hardware Setup
  1. Power off your Raspberry Pi 5 completely
  2. Attach the Hailo AI Hat to the M.2 HAT+ connector on the Pi 5
  3. Secure with the included standoffs
  4. The Hailo chip appears as a PCIe device at boot
Verify Hardware
# Check PCIe device
lspci | grep -i hailo
# Expected: Hailo Technologies Ltd. Hailo-8L AI Processor

# Check device node
ls /dev/hailo*
# Expected: /dev/hailo0
Software Installation
# Automated (recommended)
sudo bash setup/install_ai_hat.sh

# Manual install
pip3 install hailort
sudo apt-get install hailort hailort-dev

# Verify Ollama detects the Hat
ollama serve &
# Check logs for Hailo acceleration messages
Compatible Models

The Hailo-8L works best with quantized models compiled for the Hailo architecture. For LLM inference, Ollama handles the AI Hat automatically when detected.

Pre-compiled models:

  • github.com/hailo-ai/hailo_model_zoo
  • github.com/hailo-ai/hailo-rpi5-examples
Troubleshooting

AI Hat not detected

# Check PCIe is enabled
grep -i pcie /boot/config.txt
# Should have: dtparam=pciex1_gen=3

# Enable PCIe if missing
echo "dtparam=pciex1_gen=3" | sudo tee -a /boot/config.txt
sudo reboot

Slow inference despite AI Hat

# Check Hailo is being used
hailortcli fw-control identify
# Should show device info

# Check Ollama is configured for Hailo
systemctl cat ollama | grep HAILO

Power issues (thermal throttling)

# Check throttle status
sudo vcgencmd get_throttled
# 0x0 = no throttling; anything else = power or temp issue

# Reduce CPU frequency to extend battery
sudo cpufreq-set -g powersave

# Monitor temperature
watch -n 2 vcgencmd measure_temp

How to Access

Four ways to view this repository — from a quick local preview to a public URL accessible from anywhere in the world.

1
Open Directly in Browser No setup required

The simplest method. Just open index.html in any browser — no server, no internet, no dependencies.

# macOS
open /path/to/SurviveV1/index.html

# Windows (Command Prompt)
start C:\path\to\SurviveV1\index.html

# Linux
xdg-open /path/to/SurviveV1/index.html

Or: in any browser, go to File → Open File and navigate to SurviveV1/index.html.

Note: The file:// protocol works for all tabs. Copy-to-clipboard buttons require a browser (not a text editor preview).

2
Local Development Server Shareable on LAN

Serve from your computer — accessible from any device on the same Wi-Fi network.

cd /path/to/SurviveV1
python3 -m http.server 8000

Then open: http://localhost:8000

Other devices on the same network can access via your IP: http://192.168.1.X:8000

# Find your IP address:
# macOS / Linux:
hostname -I   # or: ifconfig | grep inet

# Windows:
ipconfig | findstr IPv4

GitHub Pages Public URL — accessible from anywhere

Host this HTML file for free on GitHub Pages. Once set up, anyone with the URL can view the repository documentation — no Pi required, accessible globally.

Setup (one-time, takes 2 minutes)

  1. Push this repository to GitHub (if not already there)
  2. Go to your repo on GitHub
  3. Click Settings → Pages (left sidebar)
  4. Under Source, select Deploy from a branch
  5. Branch: main (or your branch) → Folder: / (root)
  6. Click Save
  7. Wait ~2 minutes for deployment

Your site will be live at:

https://schwadb.github.io/SurviveV1/

The URL format is: https://YOUR_GITHUB_USERNAME.github.io/REPO_NAME/

Manual deploy via CLI

# Make sure index.html is committed
git add index.html
git commit -m "Update static HTML site"
git push origin main

# GitHub Pages will auto-deploy within ~2 minutes
